# Tarea 19: Recommended Campaign, "Why This Campaign?" & Candidates Comparison

## Objetivo
Implementar la sección de recomendaciones de campaña (`playground-recommendation-view.tsx`):
1. Tarjeta `BEST CAMPAIGN`:
   - Configuración: Formato creativo, Audiencia, Placement
   - Presupuesto diario recomendado
   - ROAS y Beneficio esperado
   - Sección "WHY THIS CAMPAIGN?" con 2–4 razones concisas generadas desde el estado del optimizador (ej: "✓ Highest marginal profit", "✓ Inventory available", "✓ Below saturation threshold").
   - Si no es rentable debido a stockout o saturación extrema, mostrar advertencia clara ("NO PROFITABLE CONFIGURATION - REDUCE SPEND").
2. Lista compacta `TOP ALTERNATIVES`:
   - Muestra las 3 mejores opciones por defecto (`01`, `02`, `03`).
   - Botón `[ VIEW ALL 10 ]` para expandir el ranking completo.
3. Comparador modal / inline de candidatos:
   - Al seleccionar un candidato alternativo, muestra la comparación directa `CURRENT vs RECOMMENDED` con delta visual (+₹X profit, +X.X ROAS).

## Criterios de Aceptación
- El ranking proviene del optimizador determinista.
- Las razones de recomendación son dinámicas y veraces.
- La comparación refleja diferencias matemáticas exactas entre candidatos.
