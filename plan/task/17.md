# Tarea 17: Minimal Campaign Configuration Panel & Live Budget Slider

## Objetivo
Crear el panel de configuración minimalista (`playground-minimal-controls.tsx`) con un número reducido de variables significativas:
1. Controles principales:
   - Budget Slider: Interactivo, ₹500 a ₹10,000 / día (recalcula el punto de operación dinámicamente).
   - Audience: Selector minimalista (`Broad`, `Lookalike (1-2%)`, `Retargeting / In-Market`, `Exact Search Intent`).
   - Creative: Selector (`UGC Video`, `Static Image Carousel`, `Spark Native Video`, `Product Feed Showcase`).
   - Placement: Selector (`Auto / Advantage+`, `Reels / Shorts`, `Feed Only`, `Search Grid`).
   - Duration: Selector (`7 days`, `14 days`, `30 days`).
2. Controles avanzados plegables:
   - Acordeón `[ ADVANCED ▾ ]` con guardarraíles técnicos (Target ROAS Floor, Platform Selection Toggles).
3. Botón de acción principal:
   - `[ RUN EXPERIMENT ]` con estado de ejecución progresivo.

## Criterios de Aceptación
- No satura con 15+ campos desordenados.
- El slider de presupuesto actualiza el estado en tiempo real.
- Las variables conectadas modifican de verdad los cálculos del optimizador determinista.
