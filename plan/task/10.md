# Tarea 10: Componentes de Entrada de Escenarios, Estrategias y Custom Strategy

## Objetivo
Implementar los componentes de configuración de entradas adaptados a cada escenario (Scenario Inputs Panel), selector de estrategias y configuración de estrategia personalizada en `web/src/features/decision-engine/components/`.

## Subtareas
- [x] Crear `scenario-input-panel.tsx` que renderice controles dinámicos según el tipo de shock (Stockout: inventory/spend/CVR/AOV/margin; CPM: baseline CPM/multiplier/CTR/CVR/spend; Fatigue: baseline CTR/fatigue %/spend; Undercut: price/competitor price/buy box win %/spend) con valores por defecto basados en datos reales existentes.
- [x] Implementar selector de horizonte de simulación (1 día, 7 días, 30 días) y botón de "Reset to Baseline".
- [x] Crear selector de estrategias de mitigación (`strategy-selector.tsx`) específicas para cada crisis (Do Nothing, Pause, Redirect, etc.).
- [x] Implementar configuración de estrategia personalizada (`custom-strategy-config.tsx`) con deslizadores/inputs numéricos relevantes.
