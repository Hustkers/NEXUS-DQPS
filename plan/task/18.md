# Tarea 18: Interactive Hill Response Curve Visualizer & 3 Key Metrics

## Objetivo
Desarrollar la pieza central de visualización del simulador (`playground-interactive-curve.tsx`):
1. Gran gráfico de saturación de respuesta Hill (Recharts Area / Line Chart):
   - Curva suave generada por el motor matemático.
   - Marcador interactivo del punto operativo actual (se mueve dinámicamente con el slider de presupuesto).
   - Zona de rendimiento óptimo sombreada.
   - Zona de saturación / rendimientos decrecientes.
2. Tira de solo 3 métricas clave (no 12 tarjetas):
   - `EXPECTED PROFIT`: ₹X
   - `ROAS`: X.XXx
   - `RECOMMENDED BUDGET`: ₹X/day
3. Botón y animación de ejecución de experimento (`CALCULATING` → `EVALUATING RESPONSE CURVE` → `CHECKING INVENTORY` → `OPTIMIZING` → `✓ RECOMMENDATION READY`).

## Criterios de Aceptación
- La curva refleja la función de Hill real del producto y plataforma seleccionados.
- El movimiento del slider traslada el punto en la curva sin parpadeos.
- No utiliza setTimeout falso para simular sin calcular; refleja los cálculos reales del motor.
